# App Store掲載文言(草案)

そのままApp Store Connectの各欄に貼り付けられるように、文字数制限を意識して用意した草案。
公開前に見直して調整してください。

## サブタイトル(30文字以内)

```
保存できない画像も保存できる
```
(14文字)

## プロモーションテキスト(170文字以内、審査不要でいつでも変更可)

```
長押しでの保存を防いでいるページの画像も、ImageBrowserなら保存できます。ページ内の画像をまとめて抽出することも可能。ページ内広告もブロックして快適に閲覧できます。
```
(約80文字)

## 説明文(4000文字以内)

```
ImageBrowserは、画像の保存に特化したWebブラウザです。

■ 通常保存できない画像も保存
長押しでの保存を妨げているWebページでも、画像を検出して保存できます。ニュースサイトのカード型レイアウトのように別の要素が上に重なっている画像にも対応しています。

■ ページ内の画像をまとめて抽出
ページを開くだけで、通常の写真だけでなくデザインの背景として使われている画像やスクロールしないと表示されない画像まで見つけ出し、一覧から必要なものだけ選んで保存できます(Pro機能)。

■ 広告ブロック
ページ内の広告を無料でブロックします。設定画面からいつでもON/OFFを切り替えられます。

■ ブラウザとしての基本機能
タブ・ブックマーク・検索エンジン切り替え(Google/Yahoo!/Bing)など、日常使いできる基本機能を備えています。

■ Pro機能
一括抽出機能と広告非表示は、買い切り(一度の購入で永続的に利用可)または月額・年額のサブスクリプションのいずれかで解除できます。どのプランでも同じ内容が利用できます。

■ プライバシーへの配慮
本アプリはアカウント登録を必要とせず、保存した画像はすべて利用者のiPhone/iPad内にのみ保存されます。開発者を含む第三者のサーバーへ画像が送信されることはありません。

利用規約(EULA): https://www.apple.com/legal/internet-services/itunes/dev/stdeula/
プライバシーポリシー: https://nova-droplet-464.notion.site/ImageBrowser-3e5296d4576e8167ba4ff8b30c4f8b99
```
(約600文字、余裕あり)

**Why:** サブスクリプションを提供するアプリは、App Store掲載ページの説明文にEULAへのリンクが
無いと審査でリジェクトされる(標準EULAを使う場合、App Store Connect上の専用欄ではなく
説明文中にリンクを含める必要がある、とAppleのリジェクト文言に明記されている)。

## 審査ノート(App Review情報の「メモ」欄、審査担当者向け)

権利侵害目的のアプリと誤解されないよう、用途を明確に説明しておくことを推奨します。

```
本アプリは、著作権者・サイト運営者が意図的に保存を妨げている画像を回避して取得することを目的とした
ものではなく、通常のブラウザの「長押しで画像を保存」という一般的な操作が、サイト側のJS実装
(独自のタッチイベント制御やクリックトラッキング用オーバーレイ等)によって偶発的に機能しなくなって
いるケースに対応するための、画像保存に特化したブラウザです。

- ログイン・アカウント登録は不要です。テスト用のアカウントは必要ありません。
- 保存した画像は端末のカメラロールにのみ保存され、外部サーバーへの送信は一切行いません。
- 「一括抽出」機能はPro限定(買い切り/月額/年額のいずれか)です。Sandbox環境での購入テストを
  行う場合は、jp.kaba.imagebrowser.pro.lifetime / pro.monthly / pro.yearly のいずれかを
  ご確認ください。
- ページ内広告ブロック機能は無課金・Pro問わず全ユーザーが利用できます(設定画面でON/OFF可能)。
```

## 1.2.0 の What's New と審査ノート追記(2026-10-05)

サイト名は出さない(特定サービス向けと受け取られないように一般的な表現にとどめる)。

What's New:

```
■ さかのぼり抽出(Pro機能)
一括抽出の結果画面から、画面に表示された分だけでなく、ページが持っている過去の写真までまとめて読み込めるようになりました。対応しているページでのみボタンが表示されます。

■ お問い合わせフォーム
設定画面に「お問い合わせ」を追加しました。機種・iOS・アプリのバージョンが自動で入力され、問い合わせ番号で送信済みの内容を確認できます。一括抽出の結果画面からも、うまく画像が出ないサイトを報告できます。

■ そのほかの改善
・一括抽出の結果を古い順に並べるようにしました
・写真のない場所を長押ししたときに保存メニューが出ないようにしました
・再読み込みボタンをアドレスバーの右へ移動しました
```

審査ノートへの追記(既存のメモの末尾に足す):

```
【1.2.0での追加機能】
- 「さかのぼり抽出」(Pro限定):一括抽出の結果画面に表示されるボタンです。ページ自身が読み込んでいる
  画像一覧データ(ページが表示用に取得している範囲)から、スクロールせずに過去分の画像を読み込みます。
  利用者がログインして閲覧権限を持つページの内容のみが対象で、認証の回避や非公開データの取得は行いません。
  対応する構造のページでのみ表示されるため、一般的なWebページではボタンは表示されません。
- 「お問い合わせ」:設定画面からGoogleフォームをアプリ内で開きます。機種名・iOSバージョン・
  アプリのバージョン・問い合わせ番号を自動入力します。メールアドレスは返信のためにのみ使用します。
```

What's New:

```
■ 一括抽出の結果画面に絞り込みを追加
・右上のメニューから、画像の大きさ(すべて/小を除外/中・小を除外)で絞り込めるようになりました

・複数枚の投稿で、すべての写真をまとめて抽出できるようになりました

・アプリを開き直しても、タブ一覧のページ名とサムネイルが残るようにしました
・ログイン画面が別タブで開くサイトで、ログイン後に元のタブへ戻るようにしました

・アプリのパフォーマンス改善を行いました
```

```
【バージョン1.4.0の変更点】
- 新しいアプリ内課金・サブスクリプションの追加はありません(既存の3商品のみ)。App Tracking Transparencyの許可ダイアログの挙動も変更ありません。
```

## 年齢制限(Age Rating)について

本アプリは汎用ブラウザ(任意のURLへアクセス可能)のため、Webブラウザとしての標準的な年齢設定
(「無制限のWebアクセス」に該当する項目)を選択することになります。ImageSaverと異なりSafari拡張
ではなく単独ブラウザである点に注意してください。
