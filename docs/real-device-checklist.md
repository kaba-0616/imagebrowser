# 実機チェックリスト(v0.1.0 (10)時点)

TestFlightでインストール後に確認する項目。チェックが付いたら更新すること。

## 基本操作

- [ ] 起動時にGoogle検索ページが表示される
- [ ] アドレスバーにURL/検索語を入力してページ遷移できる
- [ ] 戻る/進む/リロード・停止ボタンが機能する
- [ ] ページ内のリンク・ボタン・検索窓などがタップに正常反応する(v(4)で修正した無反応バグの確認)
- [ ] 広告バナーが画面下部に固定表示され、ページ内容を隠していない(Pro未購入時)

## タブ・ブックマーク・設定

- [ ] タブの新規作成・切り替え・削除(タブ数バッジも連動して変わる)
- [ ] ブックマークボタンをタップ→メニューが開く(トグル/一覧を見る)
- [ ] ブックマーク一覧からページを開ける、スワイプで削除できる
- [ ] 設定画面: 検索エンジン切り替え(Google/Yahoo!/Bing)が実際に反映される
- [ ] 設定画面: Pro状態表示・購入復元ボタンが動く
- [ ] 設定画面: プライバシーポリシー/サポートのリンクが開ける

## 画像保存(長押し・個別)

- [ ] 通常のページで画像を長押し→確認ダイアログ→保存できる
- [ ] **サイト側で保存をブロックしているページ**で長押し→テキスト選択にならず、確認ダイアログが出る(v(9)のCSS注入修正の確認)
- [ ] **Yahoo!ニュースのカード型レイアウト**(サムネイルの上にリンクが重なっている箇所)で長押し→画像を検出できる(v(9)のelementsFromPoint修正の確認)

## 画像保存(一括抽出、Pro限定)

- [ ] 無課金で「画像を抽出」→Paywallが出る
- [ ] Pro購入後、一括抽出→グリッド表示→選択→保存が一通り動く
- [ ] 保存後、広告バナーが消える

## 課金(Sandbox)

- [ ] 買い切り(¥1,500)の購入フローが完了する
- [ ] 月額(¥500)の購入フローが完了する
- [ ] 年額(¥5,000)の購入フローが完了する
- [ ] 購入後、どのプランでも同じPro権利(一括抽出+広告非表示)が有効になる
- [ ] 「購入を復元」で正しく復元される

## ログ機能

- [ ] 設定画面またはグリッド画面から「ログ」を開ける
- [ ] ページ読み込み・長押し検出・一括抽出・保存の各イベントが記録されている
- [ ] ログ消去ボタンで消える
